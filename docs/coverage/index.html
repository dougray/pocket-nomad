Add your coverage

There is no server and nothing is automatic. You send a file by hand; a maintainer checks it and merges it into the map.

1 · In the app

Record and export

Turn on the coverage scanner, add at least one private zone, then go to Mesh › Coverage map › Share and save the .geojson file. Preview it first under Layers › Coverage › What sharing would publish.

2a · Pull request

Add the file on GitHub

Fork the repository and add your file to docs/coverage/submissions/. You can check it first with python3 tools/coverage-merge.py --check yourfile.geojson.

2b · Or an issue

No Git needed

Open a coverage issue and attach the file (rename it to .txt or zip it if GitHub refuses .geojson).

Contributions are public. Your file, the pull request or issue, and your GitHub username are visible to everyone, and the hexagons stay on this map. Only send a file you are happy to publish. Full steps: CONTRIBUTING-COVERAGE.md.

What is in a file, and what is not

The filtering happens on your phone, before the file exists.

  • Only hexagons, about 350 m across, on a fixed worldwide grid, so files from different people line up. No exact positions.
  • Five facts per hexagon: how many times a radio was heard, the best signal, which firmware, and the first and last month.
  • No node names, IDs, messages or dates finer than a month.
  • Your private zones are cut out, along with every hexagon that touches one.
  • The merge script rejects anything else: extra fields, points, names or shapes that are not grid hexagons.
  • This page has no analytics and sets no cookies. Map tiles come from OpenFreeMap; the page sends them no referrer.
