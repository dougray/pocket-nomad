Do this now

  1. SOS is 3 short, 3 long, 3 short: • • • — — — • • • Send it as one unit with no gaps between the letters.
  2. Send it with a flashlight, a mirror, a whistle, a car horn, or by tapping on a pipe or wall.
  3. Pause, then repeat. Keep going in sets with rests between.
  4. A short signal ("dit") is 1 unit long. A long signal ("dah") is 3 units long.

Timing

  • Dit = 1 unit. Dah = 3 units.
  • Gap between parts of the same letter = 1 unit.
  • Gap between letters = 3 units.
  • Gap between words = 7 units.

Learn by sound, not by counting dots. Say "dit" and "dah" out loud.
