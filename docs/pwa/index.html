Pocket Nomad on the web

Install Pocket Nomad from your browser in a few seconds, on any phone or computer. The guides, checklists, tools and map work with no signal once it's installed.

Open it

Open the web app

Open it once while you have signal so it can save itself for offline use. Then install it with the steps below so it opens like an app.

Install on iPhone or iPad

Safari only; other iPhone browsers can't install web apps the same way.

  1. Open pocketnomad.us/app in Safari.
  2. Tap the Share button (the square with an arrow pointing up). On iPhone it's at the bottom; on iPad, at the top.
  3. Scroll down and tap Add to Home Screen.
  4. Leave the name as Pocket Nomad and tap Add.
  5. Open Pocket Nomad from your home screen once while you have signal. It's ready to use offline.

On iPhone and iPad, browsers can't use Bluetooth, so mesh radio texting needs the iPhone app.

Install on Android

Chrome, Edge or Samsung Internet.

  1. Open pocketnomad.us/app in Chrome.
  2. Tap Install when Chrome offers it, or tap the ⋮ menu › Add to home screen › Install.
  3. Open Pocket Nomad from your home screen or app drawer once while you have signal.
  4. For mesh texting, open Mesh, tap Connect a radio, and choose your radio. Keep the screen on while you use it.

Want drive mode, the coverage scanner or known radios? Get the Android app.

Install on a computer

Chrome or Edge on Windows, Mac, Linux or ChromeOS.

  1. Open pocketnomad.us/app in Chrome or Edge.
  2. Click the install icon at the right end of the address bar (a screen with a down arrow), or the menu › Install Pocket Nomad.
  3. Click Install. It opens in its own window and works offline.

Good to know

  • Private: your Medical ID, checklists and saved places stay in your browser on that device. No account, no tracking.
  • Keep it: browsers can clear sites you haven't used for weeks. Installing it, and tapping More › Ask the browser to keep it, makes that unlikely.
  • Maps: places you've looked at while online are kept for offline use, up to a few thousand map tiles. For whole regions offline, use a native app.
